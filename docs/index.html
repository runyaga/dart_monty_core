Every card below is a downloadable native example: a standalone Dart program that runs the sandboxed Python interpreter in native worker processes on your machine — not in the browser. Download the source with the link on the card, or clone the repository, and run it with the Dart SDK; inside a clone, the interpreter's native worker is picked up from lib/src/bin/, built by tool/build_worker.sh.
