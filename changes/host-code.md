### Internal

- Worker sessions answer host code as upstream's async binding does. The OS handler (`OsHandler`, internal) takes and returns `MontyValue`s: a returned `MontyNone` is `None`, and it declines only by throwing `OsCallNotHandledException`, which sends upstream's `not_handled` arm so the worker raises the call's own default (`PermissionError` naming the path for a filesystem call, `RuntimeError` for the rest). A thrown `ExternalException` raises its type, with an empty message when it has none, as a raised Python exception always carries one; a manual resume without a message still sends none, as upstream's `{'exc_type': ...}` form does. An unknown `excType` is an `ArgumentError` at a manual resume, and thrown from host code it is raised as any other throw. Any other throw now raises `Exception` with its text (was `RuntimeError`), the class upstream gives a host exception with no built-in counterpart. Internal until the cutover; the public `OsCallHandler`, `OsCallException` and the FFI/WASM paths are unchanged.
